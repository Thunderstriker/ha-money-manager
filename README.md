# HA Money

A [Home Assistant add-on repository](https://www.home-assistant.io/addons/) containing **Money Manager**:
import, categorize and visualize your online banking transactions, right inside Home Assistant.

## Adding this repository

1. In Home Assistant go to **Settings → Add-ons → Add-on Store**.
2. Click the **⋮** menu (top right) → **Repositories**.
3. Add the URL of this repository (`https://github.com/Thunderstriker/ha-money-manager`) and close.
4. Find **Money Manager** in the store, click **Install**, then **Start**.
5. Open it from the sidebar (Ingress panel) to use the dashboard.

See [`money_manager/DOCS.md`](money_manager/DOCS.md) for full usage instructions.
